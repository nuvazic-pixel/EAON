# Skill: architect

## Purpose

Use this skill when the user wants a system plan, module structure, repository design, refactor strategy, or implementation roadmap.

## Load only

- current project summary
- architecture map
- relevant constraints
- selected README / docs

## Principles

- prefer simple modular architecture
- separate core logic from tools
- make skills independently testable
- keep static context small
- use dynamic context when task-specific data is needed

## Output format

1. Target architecture
2. Folder structure
3. Component responsibilities
4. Implementation order
5. Risks
6. Next concrete step
