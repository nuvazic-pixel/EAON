# Skill: memory_summarizer

## Purpose

Use this skill when old project conversations, logs, decisions, or notes are too long and need to be compressed into reusable memory.

## Load only

- project summary
- decision log
- architecture map
- last relevant conversation chunk

## Compression rule

Keep:
- decisions
- constraints
- current state
- next actions
- risks

Remove:
- emotional noise
- duplicated brainstorming
- outdated attempts
- irrelevant logs

## Output format

1. Current project state
2. Decisions made
3. Active constraints
4. Open questions
5. Next actions
