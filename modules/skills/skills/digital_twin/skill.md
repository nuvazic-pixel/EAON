# Skill: digital_twin

## Purpose

Use this skill for infrastructure digital twin tasks involving GIS, IFC, BIM, FTTH, 5G, construction documentation, telemetry, maps, assets, photos, inspections, or field operations.

## Load only

- relevant GIS layer description
- IFC/BIM metadata
- asset schema
- map coordinates
- inspection photos metadata, not raw images unless needed
- telemetry sample
- project constraints

## Useful objects

- NVT
- trench segment
- HDD segment
- house connection
- crossing
- obstruction
- reinstatement / asphalt status
- inspection photo
- complaint / ticket
- material order
- crew activity

## Output format

1. Twin object model
2. Data fields
3. Relationships
4. Event/telemetry model
5. Dashboard idea
6. MVP implementation step
