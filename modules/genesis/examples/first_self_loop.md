# First SELF Loop Example

Run:

```bash
python -m eaon.cli --memory ./data/memory.jsonl think "Cred ca EAON trebuie sa fie local-first, dar riscul este sa il fac prea mare. Verific azi cu un test mic."
```

Expected behavior:

1. Router classifies the input.
2. Reality Debugger finds the assumption, risk, and test.
3. Council gives a compact synthesis.
4. Memory saves the input and synthesis with a hash chain.
