# EAON orchestration brief — 13 November 2026

The user's brief is engineering input. The primary references below were
checked on 13 November; external authors' results are not EAON measurements.
This change implements bounded local contracts and mock experiments, not a
reproduction of the papers or a runtime/model upgrade.

## Concrete acceptance checks

- **Reachability:** inject a false typed claim, provide a conflicting trace,
  quarantine it, observe zero inference/mock calls and no final output, then
  explicitly restore the corrected claim or revoke it. Historical v1
  checkpoints must still verify after a v2 append.
- **Workflow:** compile 24 approved synthetic traces and replay the same
  procedure. Record collection, compile-validation and replay calls separately.
  A known false precondition terminates `UNREACHABLE_GOAL` before a call; absent
  facts terminate `MISSING_REQUIRED_EVIDENCE`. An exception terminates
  `TOOL_FAILURE` without a fabricated final answer. No retries follow a terminal
  result, and only fixed inert mock handlers exist.
- **Voice:** partial, tampered, unconfirmed or mismatched transcripts are
  rejected before retrieval/inference/mock execution. The UI's offline ASR
  output becomes committed only on the user's explicit reviewed submission.
  The process-local admission seal is a harness boundary, not user identity or
  authorization for physical tools. A future verified wake-word harness must
  supply its own activation evidence; no always-on listener is added.
- **Local release:** install the pinned text/project profile into a fresh
  Python 3.12 `.venv`, preserve `.env` and stores, verify doctor/launcher and
  real Streamlit forms. Voice/model downloads remain explicit and optional.

## Installation and everyday use

The complete package adds `Instaleaza-EAON.cmd`, `Porneste-EAON.cmd`, project
creation, explicit memory save/revoke and consistent SQLite backups/restores
to new files. Existing configuration/databases are not overwritten. Backup
receipts identify the exact bytes and journal head; protect the receipt as well
as the database. A coordinated replacement of both files is not independently
authenticated by those same files.

See [local installation](../LOCAL_INSTALL.md), [evidence cards](../EVIDENCE_CARDS.md)
and [experimental workflows](../WORKFLOW_COMPILER.md). ASR accuracy, model
grounding, GPU residency, energy use and production latency remain unmeasured.
